# Joseph K. Miller — academic website

Source for [hydrodynamical.github.io](https://hydrodynamical.github.io/),
Joseph K. Miller's academic website.

[Publications](https://hydrodynamical.github.io/Publications.html) ·
[CV](https://hydrodynamical.github.io/files/CV.pdf) ·
[Teaching](https://hydrodynamical.github.io/Teaching.html)

## Structure

| Path | Contents |
| --- | --- |
| `index.html` | Homepage and introduction |
| `Publications.html` | Publications, preprints, and work in preparation |
| `CurriculumVitae.html` | CV page |
| `Teaching.html` | Teaching materials and course links |
| `files/` | PDFs and other downloadable materials |
| `photos/` | Site images |

The site uses static HTML and is published through GitHub Pages. To preview
it locally, run `python3 -m http.server 8000` from the repository root, then
open `http://localhost:8000/`.
